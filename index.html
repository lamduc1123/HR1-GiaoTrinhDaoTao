🕒 Lịch sử Phiên bản Giáo án

Ghi nhận mốc thời gian, người chỉnh sửa và nội dung thay đổi. Tự động đồng bộ với Firebase Firestore.

⚡ Cấu hình Firebase Cloud Sync

Dán đoạn mã cấu hình Firebase (Firebase Config JSON) từ Firebase Console của bạn để kích hoạt đồng bộ thời gian thực đa thiết bị:

📌 Hướng dẫn nhanh:
  1. Truy cập Firebase Console > Tạo dự án mới (miễn phí).
  2. Bật dịch vụ Firestore Database (chế độ Test Mode hoặc Production).
  3. Vào Project Settings > General, chọn biểu tượng Web (</>) để lấy firebaseConfig rồi dán vào đây.
